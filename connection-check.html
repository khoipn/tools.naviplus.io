Connection Check

Sometimes Navi+ will not open on one particular device or network. This page tests how your connection reaches the Navi+ servers, so we can find the cause. It takes about a minute. Nothing is installed.

1Run the test

Runs about 40 tiny requests and two ~0.5 MB downloads. Please keep this tab open until it finishes.

What was testedResultMedianProtocolServerDetails

2Open the Navi+ app page directly (if you saw an error)

This opens the same server the Navi+ app uses, in a new tab. If Chrome/Edge shows an error page, scroll to the very bottom of that page: there is a small code like ERR_INVALID_RESPONSE. Please type it below.

Open cdn-naviplus.com Open dash.naviplus.app

3Watch for problems (best if the error comes and goes)

Leave this tab open (you can keep working in another tab). It quietly re-checks every 20 seconds and records exactly when and where a connection fails. Stops by itself after 3 hours. Your computer must stay awake.

4Send the results to Navi+ support

Preview exactly what will be sent 
Run the test first.

This includes your public IP address and internet provider region (needed to look up your connection in our logs). It does not include passwords, store data or anything from other tabs.

Email it instead
